# Target Companies

Curated list of companies to check directly for job postings. The job-finder
skill visits each careers URL below and parses live listings from it -- this
is the primary source, checked before any supplementary web search.

Edit this list any time -- add, remove, or replace entries. One `##` heading
per company; the `Careers URL` line is required, everything else is optional
context for the finder skill (helps it judge fit/tone, not used for scoring).

Starting defaults below: two Nigeria-based companies and two fully-remote
international ones, chosen as a reasonable starting point for an AI
automation / macro analysis background. Replace or add to these freely.
